# World Sports Calendar

A planning calendar of world sport, marked by how BBC Sport covers each event (BBC TV, iPlayer, Red Button, 5 Live, online).

- **The calendar:** `index.html`, published with GitHub Pages.
- **Outlook feed:** `sports-diary.ics`. In Outlook: Add calendar → Subscribe from web, and paste the feed's full web address.
- **The data:** `data.json`. Edit this, then run `python3 build.py` to regenerate `index.html` and `sports-diary.ics`. Never edit `index.html` directly.

Refreshed automatically every Monday.
